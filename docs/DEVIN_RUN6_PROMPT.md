# DEVIN RUN 6 指示書 — リンク先言語フラグ (link_lang) の追加

あなたは Devin CLI (SWE-2) として、このワークスペースで作業する自律実装担当です。
Run 1〜5 の報告 (reports/devin-run1〜5/REPORT.md) をまず読んでください。
既存の検収済みテスト (96件) を壊さないことが前提です。

## 背景と目的

ユーザーから「リンク先は日本語ベース？」と問われ、実測では日本語ページへの
リンクは 660/2,073件 (約32%) だった。各レコードに「リンク先が日本語ページか」
を示すフラグを持たせ、検索結果とスペース (web/unified-compact.json) で
絞り込み・表示できるようにするのが本 Run の目的。

## 仕様

1. 統一スキーマに `link_lang` フィールドを追加する。値は `"ja"` または `"en"`。
   定義は厳密に「収録されているリンク URL が指すページの言語」とする。
2. 判定は ETL 内の決定的ルールで行う (推測で埋めない):
   - URL に日本語ロケールが明示されている場合に `"ja"` とする。対象パターンは
     実データで確認すること。現時点の実測では:
     - `learn.microsoft.com/ja-jp/` (azure 全550件)
     - `academy.claude.com/ja/` (anthropic 全29件)
     - Google Skills の日本語 URL (80件)
     - oracle の日本語 URL (1件)
   - 上記以外は `"en"` とする。プラットフォームに日本語版が別途存在しても、
     収録リンクが英語ページなら `"en"` のままにする (リンク先の言語が定義)。
   - 期待値: ja 合計 **660件** (azure 550 + anthropic 29 + google 80 + oracle 1)。
     実装後に実測が一致することをテストで固定する。一致しない場合は
     パターンの見落としを疑い、REPORT に差分を正直に書くこと
   - search 種別のリンク (kind=search) も URL のロケールで同様に判定する
3. CLI / 検索結果の表示に link_lang を含める (既存の出力形式を壊さない範囲で)。
   可能なら検索フィルタ `--lang ja` のような絞り込みも追加する
   (既存 CLI の設計に自然に沿う形で。無理に作らない)
4. web/unified-compact.json にも link_lang を含めて再生成する
5. テスト追加: ja 件数の固定 (合計660とカタログ別内訳)、パターン判定の
   単体テスト (ja-jp / /ja/ / 英語URL)、全件に link_lang が付くこと
6. README に link_lang の定義 (リンク先ページの言語であり、プラットフォームの
   日本語版の有無とは別であること) を明記する

## 成果物

- 上記の実装とテスト (既存96件 + 新規が全て通ること)
- `reports/devin-run6/REPORT.md`: 判定パターンの一覧、ja/en の実測内訳
  (カタログ別)、期待値660との一致確認、既知の制限を正直に書く。
  進捗は逐次更新すること
